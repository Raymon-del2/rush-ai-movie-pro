Welcome to Rush AI API

The Rush AI API provides powerful movie data and AI-powered insights for developers. Build amazing movie applications with access to TMDB data, AI chat, poster generation, and more.

Completely Free: No API key required for basic usage. Get unlimited access to all endpoints!

Base URL

https://rashai.vercel.app/api/v1

Authentication

While the API is free, you can optionally use an API key for knowledge sharing and rate limiting benefits.

X-API-Key: rush_your_api_key_here

or

Authorization: Bearer rush_your_api_key_here

AI Chat

Get AI-powered movie recommendations, insights, and analysis.

POST /api/v1/chat

Request Body:

{
  "message": "What movies are similar to Inception?",
  "context": "User likes sci-fi thrillers"
}

Response:

{
  "response": "Based on your interest in Inception, I'd recommend...",
  "usage": {
    "requests_used": 1,
    "requests_limit": 999999999,
    "tier": "free"
  }
}

Movie Search

Search the TMDB database for movies.

  }
}

Knowledge Management

Add, search, and manage knowledge in the AI's shared learning pool.

Add Knowledge

POST /api/knowledge/add
Headers:
X-API-Key: your-api-key
Body:
{
  "question": "What is the plot of Dune?",
  "answer": "Dune follows Paul Atreides..."
}

Search Knowledge

GET /api/knowledge/search
Parameters:
?q=dune&X-API-Key=your-api-key

Bulk Import Knowledge

POST /api/knowledge/import
Body:
{
  "knowledge": [
    {"question": "...", "answer": "..."},
    {"question": "...", "answer": "..."}
  ]
}

Get Knowledge Statistics

GET /api/knowledge/stats

Export All Knowledge

GET /api/knowledge/export
Parameters:
?format=json&X-API-Key=your-api-key

Get All Knowledge (Paginated)

GET /api/knowledge/all
Parameters:
?limit=50&offset=0&X-API-Key=your-api-key

Simple AI Learning

Teach your AI directly - no API key required! Perfect for quick learning.

Teach AI Directly

POST /api/learn
Body:
{
  "question": "What is the plot of The Matrix?",
  "answer": "The Matrix follows a computer hacker...",
  "tags": ["sci-fi", "action"],
  "source": "my_movie_ai"
}

No API Key Required! Anyone can teach your AI directly.

Auto-Learning

Your AI automatically learns from good responses:

  • Responses over 50 characters
  • No error messages
  • Automatically added to knowledge pool
  • Source tracked as "auto_learning"

Knowledge API Keys

Separate API keys specifically for AI learning and knowledge management.

Generate Knowledge Key

POST /api/knowledge-keys
Body:
{
  "name": "My AI Learning Key",
  "description": "For training my movie AI"
}

AI Learning Endpoint

POST /api/knowledge/learn
Headers:
X-Knowledge-Key: rk_your_knowledge_key_here
Body:
{
  "question": "What is the plot of Inception?",
  "answer": "Inception follows a thief who steals information...",
  "tags": ["sci-fi", "thriller", "nolan"]
}

List Knowledge Keys

GET /api/knowledge-keys

Get Knowledge by Source

GET /api/knowledge/by-source
Parameters:
?source=knowledge_api

Code Examples

Python

import requests

# AI Chat
response = requests.post('https://rashai.vercel.app/api/v1/chat', 
                         json={'message': 'Recommend sci-fi movies'})
print(response.json())

# Movie Search
response = requests.get('https://rashai.vercel.app/api/v1/movie-search?q=avatar')
print(response.json())

JavaScript

// AI Chat
fetch('https://rashai.vercel.app/api/v1/chat', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({message: 'Movie recommendations'})
}).then(r => r.json()).then(console.log)

// Movie Search
fetch('https://rashai.vercel.app/api/v1/movie-search?q=inception')
  .then(r => r.json()).then(console.log)

cURL

# AI Chat
curl -X POST https://rashai.vercel.app/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Best action movies"}'

# Movie Search
curl "https://rashai.vercel.app/api/v1/movie-search?q=batman"
